# React

### What is React?
  1. React is a Javascript library to build Dynamic and interactive user interfacses
  2. Developed by Facebook in 2011
  3. Used to create <b>SPA</b> (Single Page Application)
### Working of DOM (Document Object Model)
  1. Browser takes HTML and creates the DOM
  2. JS helps modify DOM based on user actions or events
  3. In big applications, Working with DOM becomes complicated
### Problem with Javascript
  1. React has a simpler mental model
  2. JS is cumbersome (complex to write & handle and also Time complex)
  3. JS is Error-prone
  4. JS is Hard to maintain
### Working of React
  1. No need to worry about quering and updating DOM elements
  2. React creates a web page with samll and reusable components
  3. React will take care of creating and updating DOM elements (***)
  4. It saves a lot of time, things are getting to be easy before using React

## JS vs REACT
  1. JS is imperative : You define steps to reach your desire state
  2. React is Declarative : You define the target UI state and then react figures out how to react that state
