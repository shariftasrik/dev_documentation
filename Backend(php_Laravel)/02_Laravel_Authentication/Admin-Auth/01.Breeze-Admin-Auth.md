## Step 1 :
1. Create & Migrate an Admin model

       php artisan make:model Admin -m
   
The task of a model in software development is to represent and manage data in an application. <br/>
Models interact with the database and encapsulate the rules, logic, and structure of the data. <br/> 

After this there will be successfully two things happened : <br/>
<ol>
    <li>A model (under Models which is under app)</li>
    <li>A migration table for Admin (under migrations which is under database) </li>
       
</ol>
